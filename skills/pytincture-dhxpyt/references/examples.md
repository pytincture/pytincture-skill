# Bundled examples

## Full app example (pytincture + dhxpyt)
Path: `assets/examples/pytincture_app/`
- `py_ui.py`: MainWindow subclass with layout, sidebar, toolbar, tabbar, grid, calendar, form
- `py_ui_data.py`: BFF class providing data
- `dataset.json` and `reconciliation.json`: data files for the example

## Minimal UI example (dhxpyt)
Path: `assets/examples/dhxpyt_ui/`
- `testui.py`: simple layout with toolbar + grid

## Standalone runtime demo
Path: `assets/standalone/`
- `index.html`: runtime example HTML
- `pytincture.js`: local runtime script
